# MJl QOL Features

Установите модуль в Foundry VTT по [ссылке на манифест](https://raw.githubusercontent.com/MJl2517/MJl-QOL-Features/main/module.json) и включите его в нужном мире. Для обновления с версии «Ильмарен — области и хиты» используйте тот же манифест. Идентификатор пакета сохраняет активацию и связи областей с чатом.

Переключатели находятся в **Настройках игры → Настроить параметры → MJl QOL Features**. По умолчанию все включены. Foundry предложит перезагрузить мир после изменения.

- **Удаление областей заклинаний из чата.** Кнопка «Убрать область» на карточке заклинания и связанной карточке урона удаляет области только этого применения и учитывает права пользователя. При выключенной настройке новые области можно удалить через список регионов сцены.
- **Без сознания при 0 хитов.** Персонажи и NPC получают состояние при падении до 0 хитов. При восстановлении до 1 хита или больше удаляется эффект, созданный модулем. Учитываются уже действующие эффекты, иммунитет и статус «Мёртв». После выключения настройки ранее назначенный эффект можно снять вручную.
- **Учёт боеприпасов в бою.** Считает боеприпасы, которые D&D5e списывает при атаках видимых персонажей в начатом бою. При завершении боя в общем чате появляется расход по каждому виду и возможный возврат с округлением вниз. Найденные боеприпасы добавляются вручную. Чтобы перейти с отдельного модуля «Боеприпасы в бою», отключите его в управлении модулями. QOL подхватит записи уже начатого боя.
- **Склад инструментов.** Откройте ящик на левой панели сцены и выберите «Настройка отображения», чтобы перенести нужные кнопки в склад. Список сохраняется отдельно для каждого пользователя мира. Для перехода на QOL отключите отдельный модуль «Склад инструментов». Сохранённый список появится в QOL.

Чтобы добавить бесконечные магические боеприпасы, создайте или скопируйте предмет типа «Боеприпасы» с подходящим подтипом (стрелы, болты, пули для пращи и т. д.). Отметьте свойства **Magical** (`mgc`) и **Returning** (`ret`), поставьте количество 1 и добавьте предмет в инвентарь персонажа. Он появится в штатном выборе боеприпасов для совместимого оружия. D&D5e не списывает такие боеприпасы, поэтому они не попадают в отчёт о расходе.

Для выстрела из оружия со свойством «Боеприпас» игроку нужен выбранный совместимый боеприпас с ненулевым остатком. Проверка действует и при быстрых бросках. Мастер может провести бросок без боеприпаса.

Если в бою расходовались магические снаряды, отчёт напоминает, что снаряды +1/+2/+3 теряют бонус при попадании. Найденный после промаха снаряд сохраняет бонус.

Отчёт также показывает количество брошенного оружия, списанного D&D5e в режимах «Бросок» и «Бросок второй рукой». Подобранное оружие добавляется в инвентарь вручную. Правило возврата половины применяется к боеприпасам.

Проверено на Foundry VTT 14.361 и dnd5e 5.3.3.
